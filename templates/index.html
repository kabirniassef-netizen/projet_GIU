📡 Référence API

Endpoints Principaux

Utilisateurs
GET /api/users/users/ - Lister tous les utilisateurs
GET /api/users/users/me/ - Récupérer l'utilisateur connecté
POST /api/users/users/ - Créer un nouvel utilisateur
Incidents
GET /api/incidents/incidents/ - Lister tous les incidents
POST /api/incidents/incidents/ - Créer un nouvel incident
GET /api/incidents/incidents/{id}/ - Détails d'un incident
POST /api/incidents/incidents/{id}/update_status/ - Mettre à jour le statut
Actifs Urbains
GET /api/assets/assets/ - Lister tous les actifs
POST /api/assets/assets/ - Créer un nouvel actif
GET /api/assets/types/ - Types d'actifs disponibles
Interventions
GET /api/interventions/interventions/ - Lister les interventions
POST /api/interventions/interventions/ - Créer une intervention
GET /api/interventions/interventions/my_interventions/ - Mes interventions
Rapports
GET /api/reports/reports/global_statistics/ - Statistiques globales
GET /api/reports/reports/incidents_by_status/ - Incidents par statut
GET /api/reports/reports/kpi_summary/ - Résumé des KPI

📚 Documentation

Architecture

Le système est construit avec une architecture 3-tiers moderne :

  • Frontend: Interface web réactive (HTML/CSS/JavaScript)
  • Backend: Django REST Framework pour l'API
  • Base de données: SQLite (développement), configurable pour production

Authentification

L'API utilise l'authentification par Token. Incluez le header suivant :

Authorization: Token votre_token_ici

Modèles de données

Utilisateur: Username, Email, Rôle, Téléphone

Incident: Titre, Description, Catégorie, Localisation GPS, Statut, Priorité

Actif: Code unique, Type, Localisation, État, Date d'installation

Intervention: Incident associé, Agent assigné, Date planifiée, Statut, Durée estimée

Technologies

  • Django 6.0.6
  • Django REST Framework 3.17
  • Python 3.14
  • SQLite 3
  • CORS Headers pour intégration frontend
